## Project Overview

This repository implements a motion planning system for autonomous vehicle, simulated using gym_envs_urdf library environment. It utilizes a kinematic bicycle model for realistic motion and Motion Primitives combined with A* algorithm for real-time path optimization. The system includes a global planner for static environment navigation and a local planner for real-time dynamic obstacle avoidance.

## Installation
Navigate to the home directory with `cd`
Running the repository requires `gym_envs_urdf`, which can be installed from source:

`git clone git@github.com:maxspahn/gym_envs_urdf.git`

To clone the repository run the following commands:

`git@github.com:marpopl/PDM-Group26.git`

## Run Instructions

To run the solution, source `gym_envs_urdf` first:

`source urdfenvs/bin/activate`

Then, change into the repository.

`cd PDM-Group26`

The main run command or the whole system is:

`python3 PDM-Group26/visualisation/path_planner.py`

However, if you are curious the behind-the-scenes, you can run parts of the project. For inspecting available environments run:

`python3 PDM-Group26/maps/rectangular_environment.py`
`python3 PDM-Group26/maps/l_shaped_environment.py`

You can also see the path generated by the global planner:

`python3 PDM-Group26/planners/global_planner.py`

Finally, you can visualize how prius is generated within the selected environment.

`python3 PDM-Group26/visualizations/visualize_with_prius.py`
